# BE72 eWEB：STUN、TCP 历史与原生弹窗

部署版本：`20261019-1`。范围为 BE72 路由器网页端，不涉及 Android APK。

## 页面与弹窗

- HUB 导航标题使用白色；图标宽度与左右边距参照同级固件菜单，标题与存储管理等栏目对齐。
- 新增 HUB → STUN 穿透。原生 Element UI 表格显示规则、协议、内网目标、公网地址、实际状态、启用开关及操作。
- 支持新建、修改、删除、启停、复制公网地址、查看地址记录。编辑只发送基础可编辑字段，保留后端高级参数。
- WireGuard、DDNS、STUN 编辑弹窗与详情弹窗继续使用固件组件。内容边距上下 10px、左右 15px；表单行距 22px；底部按钮区 10px。表单居中、标签宽度 150px，未另造移动端弹窗风格。
- TCP 目标历史只在测试完成且至少一次连接成功后写入；最多五个，规范化去重，支持删除。删除后不会被同一任务的轮询重新加入。
- TCP 测试记录由 HUB 持久保存，按路由器隔离，最多五条；列表和详情展示目标、时间、协议、结果、CPU 和内存等。失败、中止记录也明确显示真实状态。

## 部署与恢复

路由器只替换 HUB 菜单段、HUB 初始化段、页面静态资源和桥接模块；保留主包中其他已有修改。清理对应 Lua 模块编译缓存，没有重启路由器或服务。

路由器原文件与回滚脚本：`/etc/labprobe/backups/eweb-enhancements-20261019-222212/rollback.sh`。

NAS 仅更新 TCP 服务模块并重载 BE72 工作进程；BE50 工作进程和网关不重启。部署前确认没有进行中的 TCP 测试。模块与原镜像备份位置：

- `/volume1/docker/labprobe-gateway/eweb-history-backups/20261019-221759/`
- `labprobe-hub:before-eweb-history-20261019-221759`

已保存新镜像并更新容器原镜像标签，避免容器重建丢失代码修改。
